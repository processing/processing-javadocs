# processing-javadocs

> [!WARNING]
> This repository contains the source files for the [**Processing 3** Javadoc](https://processing.github.io/processing-javadocs/core/)
> 
> The source files for the **Processing 4** Javadoc can be found at [processing/processing4-javadocs](https://github.com/processing/processing4-javadocs/)
>
> The **Processing 4** Javadoc itself is hosted at https://processing.github.io/processing4-javadocs/

1) In "build" in the "processing" repo, type "ant doc"
2) Copy the three generated folders to the "processing-javadocs" repo
3) Push changes
